# Sorting Algorithms Performance Analysis

This project analyzes and compares the performance of different sorting algorithms implemented in Java.

##  Algorithms Implemented

* Quick Sort
* Merge Sort
* Insertion Sort
* Shell Sort
* Radix Sort

##  Experiment Setup

* Tested on random, sorted, and reverse sorted datasets
* Input sizes up to 250,000 elements
* Each algorithm executed multiple times and averaged
* Execution time measured using `System.nanoTime()`

##  Results

* Efficient algorithms (Merge Sort, Quick Sort) performed well on large datasets
* Insertion Sort showed strong performance on small or sorted data
* Quick Sort degraded on sorted inputs due to pivot selection
* Radix Sort showed near-linear performance under certain conditions
